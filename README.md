# FlowScroll

Бесплатная локальная утилита для плавной прокрутки колёсиком мыши на macOS 13+. Swift + SwiftUI, без сторонних зависимостей и сетевых запросов.

## Сборка и запуск

Нужны Command Line Tools (`xcode-select --install`).

```sh
bash scripts/build.sh
open build/FlowScroll.app
```

Для постоянного использования перенесите приложение в `~/Applications` или `/Applications` **до выдачи разрешений**. Нажмите значок мыши в строке меню, откройте настройки разрешений и включите FlowScroll в «Конфиденциальность и безопасность → Универсальный доступ». При необходимости перезапустите приложение. Не запускайте несколько копий одновременно.

## Возможности

- Сглаживание вертикального и горизонтального дискретного колёсика.
- Кадры синхронизированы с дисплеем под мышью: NSScreen/CADisplayLink на macOS 14+, Core Video на macOS 13.
- Каждый импульс колёсика анимируется отдельно: плавный разгон, более длинное замедление и конечная длительность 120–800 мс.
- Скорость 0.25–4×, базовый шаг 60 точек, обратное направление и отключаемое ускорение быстрого вращения.
- Отключение обработки для выбранных приложений.
- Сохранение настроек и запуск при входе через системный ServiceManagement.
- Пиксельные события колёсика без фаз жеста тоже сглаживаются (для совместимости с драйверами мышей, в том числе MX Master 3S).
- События с фазами системного жеста или инерции проходят без обработки. Это эвристика, а не определение модели устройства.
- Ctrl/⌘ + колёсико проходят напрямую, чтобы сохранить масштабирование.
- Смена направления немедленно отменяет предыдущий хвост; смена активного приложения отменяет текущую анимацию.

## Проверки

```sh
bash scripts/test.sh
bash scripts/check-display.sh
```

Автотесты работают с Command Line Tools без XCTest и полного Xcode. 13 проверок охватывают сохранение расстояния, независимость от частоты кадров, точную длительность, плавный старт, наложение импульсов, задержанный ввод, пропуск кадров, ускорение, смену направления и классификацию событий. Проверка дисплея требует обычной пользовательской графической сессии с доступом к WindowServer; в песочнице агента она не запустится.

Для сравнения версии 0.2.0: выключите обработку в оригинальном SmoothScroll, включите FlowScroll, нажмите «Сбросить» (1×, 360 мс, ускорение включено). Медленный шаг даст 60 точек, при быстром вращении шаг увеличивается до 7×. Это соответствует исследованным значениям шага и времени установленного оригинала, но кривая замедления у FlowScroll собственная; идентичность ощущения не проверена.

Для ручной проверки после выдачи доступа: длинная страница в браузере, Finder, горизонтальная прокрутка, исключённое приложение, трекпад, Ctrl/⌘ + колёсико, выключение и повторное включение. Не включайте одновременно две утилиты сглаживания; меню предупреждает, если оригинальный SmoothScroll запущен.

## Ограничения первой версии

Это собственная реализация базовой плавной прокрутки, а не полная копия SmoothScroll. Если драйвер мыши добавляет фазы системного жеста, такие события обходят сглаживание; индивидуальные профили скорости по программам пока отсутствуют. Статус последнего ввода виден в меню приложения. Агрегированные счётчики входящих событий и отправленных кадров обновляются раз в две секунды в `NSTemporaryDirectory()/flowscroll-status-<uid>.json`; содержимое окон, координаты и имена программ туда не записываются. События создаются через публичный Core Graphics CGEvent API: https://developer.apple.com/documentation/coregraphics/cgevent

Сборка подписывается локальной ad-hoc подписью, без Apple Developer ID и нотарификации. Пересборка может потребовать повторной выдачи разрешения. Качество прокрутки и автозапуск нужно проверить на конкретном Mac с реальной мышью.
